## Small Project Ideas

### 1. Simple Calculator--  Done

Features:

* Take two numbers from user
* Ask for operation (+, -, *, /)
* Use `if-else` or `switch`

Example:

```text
Enter first number: 10
Enter second number: 5
Enter operation: *
Result = 50
```

---

### 2. Even/Odd Checker -- Done

Input a number and tell whether it is even or odd.

Bonus:

* Count how many even numbers exist from 1 to N.

---

### 3. Multiplication Table Generator --Done

Input any number and print its table.

Example:

```text
Enter number: 7

7 x 1 = 7
7 x 2 = 14
...
7 x 10 = 70
```

---

### 4. Number Pattern Printer -- Done

Use nested loops.

Example:

```text
*
**
***
****
*****
```

Or:

```text
1
12
123
1234
12345
```

---

### 5. Student Grade System -- Done

Input marks.

Output:

```text
91 -> Grade A
82 -> Grade B
74 -> Grade C
```

Use `if-else`.

---

### 6. Simple ATM Simulation -- Done

Menu:

```text
1. Check Balance
2. Deposit
3. Withdraw
4. Exit
```

Use loops and conditionals.

(No functions needed yet.)

---

### 7. Password Checker -- Done

Store a password:

```c
int password = 1234;
```

Give user 3 attempts.

Output:

```text
Access Granted
```

or

```text
Access Denied
```

---

### 8. Mini Quiz Game -- Done

Ask 5 questions.

Example:

```text
Capital of India?
1. Mumbai
2. Delhi
3. Kolkata
```

Calculate score.

---

### 9. Sum of Digits  -- Done 

Input:

```text
456
```

Output:

```text
15
```

(Hint: `%` and `/` operators.)

---

### 10. Reverse a Number -- Done

Input:

```text
1234
```

Output:

```text
4321
```

This is an excellent loop exercise.
