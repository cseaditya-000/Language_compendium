### Key Python Concepts Covered

#### 1. **Python Basics**
- Variables, naming conventions, and assignment.
- Data types: strings, integers, floats, booleans, complex numbers.
- Expressions vs. statements.
- Printing/output and input handling with `input()` function.
- Comments and importance of indentation for code blocks.

#### 2. **Data Structures**
- **Lists**: Creation, indexing, slicing, appending, extending, popping, inserting, sorting, copying.
- **Tuples**: Immutable sequences, indexing, slicing, concatenation.
- **Dictionaries**: Key-value pairs, adding/removing keys, getting default values, iteration.
- **Sets**: Unordered collections, no duplicates, set operations (union, intersection, difference), subset/superset.
  
#### 3. **Control Flow**
- If, elif, else statements; boolean expressions.
- Logical operators (`and`, `or`, `not`).
- For loops, including `range()` and `enumerate()`.
- While loops with conditions, counters.
- Break and continue statements.

#### 4. **Functions**
- Definition with `def`; parameters and arguments.
- Optional/default arguments.
- Return statements and multiple return values.
- Variable scope: local vs global.
- Nested functions and closures.
- Lambda (anonymous) functions.
- Decorators to modify function behavior.
- Function annotations and type hinting (optional static type checks with mypy).

#### 5. **Object-Oriented Programming**
- Defining classes, special methods (`__init__`, `__str__`).
- Instance methods and attributes, use of `self`.
- Creating instances/objects.
- Inheritance and method overriding.
- Polymorphism: same method names across classes with different behaviors.
- Operator overloading to customize comparison and arithmetic operations.

#### 6. **Modules and Libraries**
- Importing modules (standard library and user-created).
- Python Standard Library highlights (math, random, os, json, etc.).
- Managing Python packages via `pip`.
- Path and multi-file package structure with `__init__.py`.

#### 7. **Advanced Topics**
- Exception handling with try-except-else-finally; raising exceptions; custom exception classes.
- The `with` statement for resource management (e.g., file handling).
- Command-line arguments parsing with `sys.argv` and `argparse`.
- Functional programming helpers: `map()`, `filter()`, `reduce()` (with `functools`).
- Recursion with base cases and factorial example.

#### 8. **Strings**
- String literals (single, double, triple quotes for multiline).
- Concatenation (`+`), appending (`+=`).
- String methods (`upper()`, `lower()`, `title()`, `startswith()`, `isdigit()`, etc.).
- Escape characters for quotes and special formatting (`\n`, `\\`).
- Indexing and slicing strings.
- f-strings for embedding variables and expressions.

#### 9. **Booleans**
- Boolean operators and truthy/falsy evaluation rules.
- `all()` and `any()` built-in functions to evaluate collections of booleans.

### Blackjack Project: Core Concepts and Structure

- **Classes**:
  - `Card`: represents a playing card with attributes `suit` and `rank`; uses `__str__` to display cards as "K of Hearts".
  - `Deck`: a collection of `Card`s; supports shuffle, deal functions.
  - `Hand`: cards held by a player or dealer, tracks value with blackjack rules for aces.
  - `Game`: controls game flow including:
    - Number of games to play.
    - Player and dealer hand management.
    - Input handling for player actions (hit/stand).
    - Dealer automatic card drawing until value >= 17.
    - Win/loss/draw logic considering blackjack and busting conditions.

- **Game Mechanics**:
  - Deck is shuffled at the start of each game.
  - Both player and dealer get two initial cards.
  - Player can hit or stand; input validated.
  - Dealer reveals only second card until player stands.
  - Values calculated with ace adjustment (11 or 1).
  - Round ends when player/dealer busts or stands, hand values compared.
  - Loop repeats for number of games entered by user.

### Important Terms and Concepts

| Term                   | Definition                                                                                 |
|------------------------|--------------------------------------------------------------------------------------------|
| **Immutable**          | An object whose state cannot be modified after creation (e.g., strings, tuples, ints).     |
| **Mutable**            | Can be changed after creation (e.g., lists, dictionaries, sets).                          |
| **Function**           | A reusable block of code defined with `def` that can accept parameters and return values. |
| **Class**              | Blueprint for creating objects encapsulating data and behavior.                           |
| **Method**             | A function defined inside a class acting on instances (`self`).                           |
| **Module**             | A Python file containing definitions and statements, importable into other files.        |
| **Decorator**          | A callable that modifies the behavior of a function or method without changing its code.  |
| **Lambda Function**    | An anonymous function defined with `lambda` keyword; single expression only.             |
| **Closure**            | A nested function that remembers variables from its enclosing scope.                     |
| **Exception**          | An error event that interrupts normal flow, catchable with try/except.                   |
| **Recursion**          | A function calling itself to solve a problem by breaking it down into simpler subproblems.|
| **Polymorphism**       | Different classes having methods with the same name but different implementations.       |
| **Operator Overloading** | Defining custom behavior for Python operators in user-defined classes.                  |

### FAQs

**Q: How does Python handle user input?**  
A: Using the `input()` function that pauses execution and returns user-typed string.

**Q: What is the difference between a list and a tuple?**  
A: A list is mutable (can be changed), a tuple is immutable (cannot be changed).

**Q: How are exceptions handled in Python?**  
A: Using try-except blocks; optionally with else and finally blocks for extended control.

**Q: What is an f-string and why use it?**  
A: A formatted string literal (prefixed by `f`) that embeds expressions inside `{}` for readable string construction.

**Q: Can I write Python code online without installation?**  
A: Yes, platforms like Replit allow running Python code in-browser with no setup.

**Q: What is pip?**  
A: Python package installer utility to add third-party libraries from PyPI (Python Package Index).

**Q: How do classes enhance Python programming?**  
A: They enable encapsulation of data and behavior, promote reuse via inheritance, and model real-world entities.
